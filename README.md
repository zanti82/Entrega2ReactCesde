# 🛍️ Proyecto: Página de Compras Online

Este proyecto consiste en la creación de una página web de compras online a partir de una maqueta base,
utilizando React como tecnología principal.

## 🚀 Tecnologías utilizadas

* React
* React Router DOM
* CSS

## 📂 Estructura del proyecto

El proyecto está organizado siguiendo buenas prácticas, separando responsabilidades en diferentes carpetas:

* `components/` → Componentes reutilizables (Navbar, Cards, Footer, etc.)
* `pages/` → Vistas principales (Inicio, Productos, Contacto)
* `styles/` → Archivos CSS
* `assets/` → Imágenes y recursos
* 'routes/` → Imágenes y recursos

## 🔄 Navegación

Se implementó enrutamiento mediante React Router, permitiendo la navegación entre páginas sin recargar el navegador.

* Uso de `BrowserRouter`, `Routes` y `Route`
* Navegación mediante `Link` entre componentes

## 🧠 Manejo de estado

Se utilizó el hook `useState` para:

* Capturar información del usuario
* Manejar datos dinámicos en la aplicación

## 💾 Persistencia de datos

Se implementó almacenamiento en el navegador mediante `localStorage` para guardar información y mantenerla disponible entre sesiones.

## 🎯 Objetivo

Construir una aplicación funcional tipo e-commerce, aplicando conceptos clave de React como:

* Componentización
* Manejo de estado
* Navegación entre vistas
* Organización escalable del proyecto
